# Contrato de evidencia de calidad

Cada comprobación debe registrar:

- conjunto y periodo analizados;
- denominador: mensajes, versiones o eventos actuales;
- consulta o código ejecutado;
- resultado antes y después, si hay transformación;
- acción aplicada;
- limitación conocida;
- fecha, `run_id` y referencia a originales o cuarentena.

Dimensiones mínimas: completitud, unicidad, validez, consistencia, actualidad
y exactitud. Los casos sintéticos dañados se etiquetan separadamente y no se
mezclan con el análisis de datos reales.
